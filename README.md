I developed this comprehensive database redesign for View Ridge Gallery as part of my OMIS 652 course, addressing key operational challenges faced by the 30-year-old art gallery. The legacy system lacked features like visitor tracking, online ratings, employee commission monitoring, and structured event planning. I analyzed these gaps from both a business and user perspective, then designed and implemented six new relational tables—integrated with foreign keys to ensure data consistency. Through purpose-built SQL queries, this project enhances customer engagement, supports staff accountability, and streamlines gallery operations. It reflects my ability to translate real-world problems into scalable data solutions.
